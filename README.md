# flat-hunt

Пошук квартири у Львові в радіусі від церкви св. Анни (вул. Ярослава Мудрого).

## Швидкий старт

```bash
cp .env.example .env && $EDITOR .env       # токен Telegram, за бажання Mongo
uv sync
uv run flat-hunt collect --quiet --force   # зібрати все, нічого не слати
uv run flat-hunt report                    # подивитись найкраще
uv run flat-hunt collect --seed --force    # позначити бекленг переглянутим
uv run flat-hunt collect                   # далі — лише нове, з пушем у Telegram
```

Ще команди: `stats`, `sync`, `chatid`, `test`, `watch`.

## Спільний стан між машинами

Якщо заданий `MONGODB_URI`, збирач перед кожним проходом підтягує з Mongo
позначки «вже надіслано» і геокеш, а після проходу вивантажує свій стан.
Завдяки цьому VPS і локальні запуски не шлють ту саму квартиру двічі.
SQLite лишається робочим сховищем: коли Mongo недоступна, прохід просто
йде без синхронізації і нічого не ламається.

## Ознаки шахрайства

`flathunt/risk.py` нічого не відсіює, лише маркує: вік акаунта продавця
(є прямо в даних OLX як `user.created`), прохання передоплати, відмова
показати квартиру особисто, ціна нижча за медіану вибірки на 40%+,
відсутність фото, телефон у тексті замість кнопки OLX. Високий рівень
знімає 20 балів, середній — 8.

## Дедуплікація

Ключ об'єкта — нормалізована вулиця, площа, поверх і ціна з кроком 500 грн,
тож «вул. Генерала Чупринки, 59» і «Чупринки 59» з різних джерел збігаються.
Канонічним лишається оголошення **від власника**: коли ту саму квартиру
подали і власник, і агенція, у сповіщення піде та, де немає комісії.

## Як воно влаштоване

Збирач детермінований, без LLM. Уся інформація береться з
`__PRERENDERED_STATE__` сторінки списку OLX: опис, параметри, поверх,
планування, фото, `isBusiness`, `createdTime`. Одна сторінка = 40 повних
оголошень, окремо кожне тягнути не треба — три пошуки закриваються
шістьма запитами.

**Координати OLX не використовуються.** Сайт віддає центроїд району:
на 80 оголошень припадає 17 унікальних точок, у всіх `show_detailed: false`.
Замість них вулиця розпізнається з тексту й геокодується через Nominatim
з кешем у SQLite.

**Перехресна перевірка району.** Nominatim промахується по номеру будинку
на довгих вулицях (Городоцька 173 знаходилась у Франківському районі,
хоча OLX каже Залізничний). Якщо райони не збігаються, точка
відкидається й береться вулиця без номера, а запис позначається
`street_conf = сумнівно`.

## Файли

| Файл | Що робить |
|---|---|
| `config.yaml` | точка відліку, тіри відстані, вилки цін, відсіви |
| `flathunt/olx.py` | збір і нормалізація OLX |
| `flathunt/geo.py` | вулиця з тексту, Nominatim, відстань |
| `flathunt/score.py` | жорсткі відсіви й бал 0–100 |
| `flathunt/store.py` | SQLite, дедуплікація, кеш геокодування |
| `flathunt/risk.py` | ознаки шахрайства |
| `flathunt/sync.py` | спільний стан у MongoDB |
| `flathunt/notify.py` | картки в Telegram і мітка на карті |

## Вилки цін

Задані так, щоб ціна **на особу** лишалась близько 11 тис. грн:
1к на одного 9–14к, 2к на двох 15–23к, 3к на трьох 22–33к.
Трикімнатна за 33 тисячі дешевша для тебе, ніж однушка за 14.

## Cloudflare фільтрує за TLS, а не за заголовками

Найнеочевидніша пастка проєкту. З Fedora звичайний `requests` отримує 200,
а з `python:3.13-slim` у контейнері — 403, **при тій самій IP-адресі**.
Повний набір браузерних заголовків не допомагає, `urllib` теж 403.
Причина в рукостисканні TLS: OpenSSL у Debian має інший порядок шифрів
і розширень, ніж у Fedora, і Cloudflare це розпізнає.

Тому збирач ходить через `curl_cffi` з `impersonate="chrome"` — він
відтворює рукостискання справжнього Chrome. Якщо пакета нема,
код тихо відкочується на `requests` (працює локально на Fedora).

## Розгортання через Coolify

Доступ по SSH не потрібен, усе робиться з UI.

1. Запушити репозиторій (GitHub / приватний Git — байдуже).
2. У Coolify: **New Resource → Docker Compose**, вказати цей репозиторій.
   Compose-файл підхопиться сам.
3. У вкладці **Environment Variables** додати:
   - `TELEGRAM_TOKEN`
   - `TELEGRAM_CHAT_ID`
   - `MONGODB_URI` (за бажання)

   Саме тут вони й мають жити — у git вони не потрапляють ніколи.
4. Том `flat-hunt-data` створиться сам, база переживає передеплої.
5. Deploy. У логах має бути `watch: інтервал 600 с`.

Перший запуск після деплою варто зробити з `--seed`, інакше прилетить
уся наявна база одразу:

```bash
# у терміналі контейнера всередині Coolify
flat-hunt collect --seed --force
```
